## Third-party libraries

- Leaflet — interactive maps, BSD-2-Clause license: https://leafletjs.com/
- jsPDF — browser PDF generation, MIT license: https://github.com/parallax/jsPDF
- OpenStreetMap contributors — map tiles and data attribution: https://www.openstreetmap.org/copyright

Leaflet and jsPDF runtime files are vendored under `assets/js/plugins/`. OpenStreetMap attribution is displayed by the map control.

## Brand and interface icons

The logo, favicon, and interface icons are original SVG assets included in the project. Controls use inline SVG rather than an icon font or Unicode symbols.
